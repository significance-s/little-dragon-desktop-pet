下载 [Windows x64 发行包](https://github.com/significance-s/little-dragon-desktop-pet/releases/download/v0.2.1/LittleDragonPet-v0.2.1-Windows-x64.zip)，完整解压后双击“小龙娘.exe”。无需安装 Python 或其他依赖。

## 主要功能

- 七种原画风透明动画、拖动互动、大小调节和系统托盘。
- 专注监督、答题卡、学习日历和每日复盘小结。
- 分组右键菜单，互动动作与专注控制分别收进子菜单。
- 自定义日期提醒，按目标日期显示剩余天数。

## 使用提示

右键打开功能菜单；Esc 隐藏到托盘，托盘“退出”彻底关闭程序。
答题卡需自行导入题单；使用方式见 [README](https://github.com/significance-s/little-dragon-desktop-pet#readme)。

设置与学习记录保存在本机，更换程序文件不会清空记录。
程序尚未数字签名，请从本项目下载，不要关闭安全软件。
