# 小龙娘桌宠 · Windows 使用指南

## 启动

完整解压发行 ZIP，双击“小龙娘.exe”。无需安装 Python 或第三方依赖，也无需管理员权限。
更新程序前，请先从系统托盘退出旧实例。

## 基本操作

- 左键拖动移动桌宠；单击摸头，双击招手。
- Ctrl + 滚轮调整大小，也可在右键菜单中输入尺寸。
- “开始专注”设置目标与时长，“专注控制”负责暂停、继续或结束。
- “学习日历与小结”查看当日统计、补记题数、保存复盘或复制小结。
- “日期倒计时”设置、显示或清除日期提醒。
- “答题卡”查看已导入的本地题单，记录每题状态和备注。
- Esc 隐藏到托盘，计时继续；托盘“退出”彻底关闭程序。

答题卡需要自行导入题单，不自带在线题库，不会自动连接 AI 服务。
题单格式与导入说明见 [仓库文档](https://github.com/significance-s/little-dragon-desktop-pet/blob/main/desktop_pet/CODEX_BRIDGE.md)。

## 日历与复盘

日历可以切换月份、选择日期和回到今天，有记录的日期下方显示圆点。
专注时长不包含暂停时间；同一答题卡题目反复保存不会重复加题数。
“额外补记”填写答题卡以外的练习数量，不要重复填入自动统计的题目。

复盘备注在切换日期或关闭日历时保存，也可点击保存按钮。
复制小结只会将文字放入剪贴板，不会自动发送或上传。

## 数据与升级

设置和记录默认保存于：

~~~text
%LOCALAPPDATA%\LittleDragonDesktopPet\
~~~

在资源管理器地址栏粘贴此路径即可打开。config.json 为设置，data/ 为学习和答题记录，
logs/startup.log 为启动错误日志。更换程序文件不会清空记录；升级前建议备份此目录。

日历按 UTC+8 归档。专注记录每 15 秒以及暂停、结束、退出时保存；
异常断电或崩溃可能损失最近不足 15 秒的计时。

## 排错

没有看到桌宠时，先检查托盘和隐藏图标区域。启动失败时查看 logs/startup.log。
反馈问题请附上 Windows 版本与提示内容，并隐去私人题单、备注等信息。

程序尚未数字签名，Windows 可能提示未知发布者。
请只从 [本项目 Releases](https://github.com/significance-s/little-dragon-desktop-pet/releases) 下载，
不要为绕过拦截而关闭安全软件。
