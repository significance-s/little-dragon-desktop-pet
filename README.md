# 小龙娘桌宠

一只可以陪你学习的小龙娘：在桌面互动、提醒专注、记录每天的练习与复盘。
适用于 Windows x64，无需连接 AI 服务。

<img src="pic/gif/00_待机母版.gif" alt="小龙娘待机动画" width="260">

## 下载与启动

1. 打开 [最新发行版](https://github.com/significance-s/little-dragon-desktop-pet/releases/latest)。
2. 在 Assets 中下载 Windows x64 的 ZIP 发行包，**不要选择 Source code**。
3. 完整解压，双击其中的 **小龙娘.exe**。

EXE 版不需要安装 Python 或其他依赖。程序没有安装向导，不要直接在压缩包里运行。
更新版本前，先从系统托盘退出旧实例。

## 功能

- **桌面陪伴**：七种透明动画，支持拖动、点击互动和大小调节。
- **专注监督**：设置目标和时长，支持暂停、继续与完成反馈。
- **学习日历**：按日期查看专注时长、题目状态和卡点，补记练习、保存复盘。
- **日期提醒**：自定义提醒名称与目标日期。
- **答题卡**：导入本地题单，记录每题状态和备注，导出答题回执。
- **系统托盘**：随时显示、隐藏或退出桌宠。

## 常用操作

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 移动桌宠，专注和日期面板随之移动 |
| 单击 / 双击 | 摸头 / 招手 |
| 右键 → 互动动作 | 选择动作 |
| Ctrl + 滚轮 / 右键 → 调整大小 | 缩放桌宠，支持输入尺寸 |
| 右键 → 开始专注 | 设置本轮目标与时长 |
| 右键 → 专注控制 | 暂停、继续、完成或结束本轮 |
| 右键 → 学习日历与小结 | 查看每日记录，保存复盘、复制小结 |
| 右键 → 日期倒计时 | 设置、显示或清除日期提醒 |
| Esc | 隐藏到托盘，专注计时继续 |
| 托盘 → 显示 / 隐藏小龙娘 | 恢复或隐藏桌宠 |
| 托盘 → 退出 | 彻底关闭程序 |

### 学习日历

点击日期查看当日小结，用左右箭头切换月份，点击“今天”回到当天。有记录的日期下方会显示圆点。

专注时长来自监督计时，暂停时不累计。答题卡的状态变更会计入当日统计，同一题反复保存不会重复增加题数。
“额外补记”用于填写答题卡以外的练习数量，避免与自动统计重复计算。

复盘备注可手动保存，也会在切换日期或关闭日历时保存。
“复制当日小结”可把专注、题数和复盘复制为文字，便于自行分享或整理。

学习文件损坏或不可读时，日历会停用编辑并保留原文件。
保存失败时输入仍保留，可复制未保存草稿、重试或明确放弃；关闭前会询问如何处理。

### 答题卡

答题卡使用本地 JSON 题单，**不自带在线题库，也不会自动连接 Codex 或其他 AI 服务**。
可以通过外部工具按协议导入题单；全部题目确认状态后，可导出回执并复制摘要。

题单格式和导入方式见 [答题卡文件协议](desktop_pet/CODEX_BRIDGE.md)。

## 数据保存与升级

EXE 版的设置和学习记录保存在：

~~~text
%LOCALAPPDATA%\LittleDragonDesktopPet\
~~~

可直接将这一路径粘贴到资源管理器地址栏打开。
其中 config.json 保存桌宠设置，data/ 保存题单、答题进度和学习日历。
替换程序文件不会清空这些记录；升级前建议备份此目录。

程序不会自动上传学习记录，也不会自动向对话发送小结。
日历和日期提醒按 UTC+8 计算。专注记录每 15 秒保存一次，暂停、结束和退出时也会保存；
异常断电或崩溃可能丢失最近不足 15 秒的计时。

## 常见问题

**双击后没有看到桌宠？**

先查看系统托盘及其隐藏图标区域，尝试“显示 / 隐藏小龙娘”。
若启动报错，查看数据目录中的 logs/startup.log；反馈时请隐去个人题单与备注。

**Windows 提示未知发布者？**

当前 EXE 尚未数字签名。请确认下载自本仓库的 Releases；如被安全软件拦截，请反馈提示内容，
不要关闭安全软件或运行来源不明的副本。

**答题卡里没有题目？**

需要先导入题单，详见上方的答题卡说明。日历的手动补记和专注计时不依赖题单。

## 从源码运行

需要 Windows、Python 3.12 或 3.13，并安装 pip 与 Tcl/Tk 组件。
完整下载并解压源码后，双击根目录的 run.bat；首次运行会联网安装依赖到项目自己的 .venv。
